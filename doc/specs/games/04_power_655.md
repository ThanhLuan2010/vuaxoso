# ĐẶC TẢ KỸ THUẬT GAME: POWER 6/55 (`power_655`)

## 1. TỔNG QUAN GAME
- **Mã định danh hệ thống (`gameType`)**: `power_655`.
- **Nhóm trò chơi**: Xổ số Jackpot tích lũy Vietlott (Ma trận 6/55).
- **Lịch mở thưởng**: **Thứ 3, Thứ 5, Thứ 7** hàng tuần lúc **18:00**.
- **Thời gian chốt vé (Cutoff Time)**: **17:45** cùng ngày (trước giờ mở thưởng 15 phút).
- **Quy cách quay thưởng**:
  - Rút ngẫu nhiên **6 quả bóng chính** từ tập hợp `01` đến `55`.
  - Rút thêm **1 quả bóng đặc biệt (Bonus Number)** từ 49 quả bóng còn lại để xác định giải **Jackpot 2**.
- **Cơ chế mở thưởng**: Nhập kết quả thủ công từ CMS theo kết quả quay thưởng chính thức của Vietlott.

## 5. THUẬT TOÁN DÒ THƯỞNG BACKEND (`prizeService.ts`)

```typescript
// 6 số chính và 1 số bonus
const mainWins = new Set(draw.winningNumbers); // Set of 6 numbers
const bonusNum = draw.specialNumber;

for (const item of order.items) {
  // Lấy danh sách các tổ hợp 6 số (với vé thường là 1 bộ, với vé bao sinh các tổ hợp C(N, 6))
  const combos = item.playType === 'Cơ bản' 
    ? [item.numbers] 
    : getCombinationsList(item.numbers, 6);

  for (const combo of combos) {
    const matchMain = combo.filter(n => mainWins.has(n)).length;
    const matchBonus = combo.includes(bonusNum);

    if (matchMain === 6) {
      itemPrize += JACKPOT_1_VALUE;
    } else if (matchMain === 5 && matchBonus) {
      itemPrize += JACKPOT_2_VALUE;
    } else if (matchMain === 5) {
      itemPrize += 40000000;
    } else if (matchMain === 4) {
      itemPrize += 500000;
    } else if (matchMain === 3) {
      itemPrize += 50000;
    }
  }
}
```

- Danh sách kỳ quay lọc theo `power_655`.
- Modal nhập kết quả:
  - 6 ô nhập cho 6 số chính (từ 01 đến 55, không được trùng nhau).

- Nút "Xác nhận & Dò vé": Hệ thống thực hiện dò vé hàng loạt và cộng thưởng tự động.
