# ĐẶC TẢ KỸ THUẬT GAME: LÔ TÔ 2, 3, 5 SỐ (`loto_235`)

## 1. TỔNG QUAN GAME
- **Mã định danh hệ thống (`gameType`)**: `loto_235`.
- **Nhóm trò chơi**: Xổ số Lô tô Điện toán truyền thống theo kết quả Xổ số Miền Bắc (XSMB).
- **Lịch mở thưởng**: **18:15 hàng ngày** theo lịch quay XSMB.
- **Thời gian chốt vé (Cutoff Time)**: **18:10** cùng ngày (trước giờ mở thưởng 5 phút).
- **Nguồn kết quả**: Bảng kết quả 27 giải của Xổ số Miền Bắc (đặc biệt là Giải Đặc Biệt và Giải Nhất).
- **Cơ chế mở thưởng**: Lấy chung kết quả từ kỳ quay XSMB được nhập trên CMS.

## 2. GIAO DIỆN & LUỒNG THAO TÁC TRÊN MOBILE APP (`StandardLotteryLayout.tsx`)

### 2.1. Màn hình chọn cược Lô Tô 2, 3, 5 Số
1. **Header**:
   - Nút Back (`<ArrowLeft />`).
   - Tiêu đề: "LÔ TÔ 2, 3, 5 SỐ - THEO XSMB".
   - Tỉ lệ trả thưởng cao nhất: "🏆 Lô tô 5 số trúng lên tới x20.000 lần".
   - Số dư ví realtime.
2. **Khu vực Thông tin Kỳ Quay & Đếm Ngược**:
   - Hiển thị ngày mở thưởng XSMB hôm nay.
   - Đồng hồ đếm ngược đến 18:10.
3. **Thanh chọn Phân Loại Cược (Tabs)**:
   - **Lô Tô 2 Số**:
     - Chọn 1 số gồm 2 chữ số từ `00` đến `99`.
     - Tỉ lệ ăn: `1 ăn 70` (hoặc cấu hình lên tới 99.9).
     - Quy luật: Trùng 2 số cuối của Giải Đặc Biệt XSMB.
   - **Lô Tô 3 Số**:
     - Chọn 1 số gồm 3 chữ số từ `000` đến `999`.
     - Tỉ lệ ăn: `1 ăn 400` (hoặc cấu hình lên tới 980).
     - Quy luật: Trùng 3 số cuối của Giải Đặc Biệt XSMB.
   - **Lô Tô 5 Số**:
     - Chọn 1 số gồm đúng 5 chữ số từ `00000` đến `99999`.
     - Tỉ lệ ăn: `1 ăn 20.000`.
     - Quy luật: Trùng khớp chính xác cả 5 chữ số của Giải Đặc Biệt XSMB.
4. **Bàn Phím Số / Nhập Nhanh**:
   - Chế độ chọn số ma trận từng hàng hoặc nhập chuỗi số cách nhau bởi dấu phẩy.
   - Hỗ trợ tối đa 6 bảng cược (Bảng A đến F).
   - Nút `TC` và `Xóa` nhanh.
5. **Bộ chọn Tiền Cược (Multiplier)**:
   - Mức cược tối thiểu: `10.000 VNĐ / số`.
   - Phím tắt cược: `10k`, `20k`, `50k`, `100k`, `200k`, `500k`.
6. **Thanh Footer & Đặt Vé**:
   - Tạm tính tổng tiền cược.
   - Nút [Thêm giỏ hàng] & Nút [Đặt vé ngay].

### 4.2. Thuật toán Dò Thưởng Lô Tô (`prizeService.ts`)
```typescript
// Lấy giải Đặc Biệt của kỳ quay XSMB cùng ngày
const dbMb = drawMB.winningNumbers[0]; // Chuỗi 5 số, ví dụ "83472"

for (const item of order.items) {
  const num = item.numbers[0];
  const mult = item.multiplier || 1;
  const base = item.baseCost || 10000;

  if (item.playType === 'Lô Tô 2 Số') {
    if (num === dbMb.slice(-2)) {
      totalPrize += base * mult * 70;
    }
  } else if (item.playType === 'Lô Tô 3 Số') {
    if (num === dbMb.slice(-3)) {
      totalPrize += base * mult * 400;
    }
  } else if (item.playType === 'Lô Tô 5 Số') {
    if (num === dbMb) {
      totalPrize += base * mult * 20000;
    }
  }
}
```
